### Headline

### Key Features

- Audio transcribed and processed by AI in real-time

- See conflict hotspots on interactive map

- Risk level assessment (Low/Medium/High)

- Works without internet connection

## 🔧 Slide 5: How It Works

### Headline
**From Voice Report to Community Alert in 10 Seconds**

### User Flow (5 Steps)

```
1️⃣  USER REPORTS
   ↓
   "Large herd approaching my farm"
   (Voice or Text Input)

2️⃣  AI PROCESSES
   ↓
   Gemini 2.5 Flash analyzes:
   - Voice/text transcription
   - Location coordinates
   - Weather context
   - Historical data

3️⃣  RISK ASSESSMENT
   ↓
   AI generates:
   - Risk level (Low/Medium/High)
   - A2UI blueprint (dynamic UI)
   - Recommended actions

4️⃣  DYNAMIC UI RENDERS
   ↓
   GenUI displays:
   - Color-coded risk banner
   - Map with threat location
   - Action buttons (Share, etc.)

5️⃣  ALERT SHARED
   ↓
   User shares to:
   - WhatsApp groups
   - Facebook
   - Twitter
   - Any social platform
```

## 🎨 Design Notes

### Visual Style
- **Color Palette**: Earth tones (browns, greens, reds) - reflects Nigerian rural context
- **Typography**: Roboto (clean, modern, supports multiple languages)
- **Icons**: Simple, flat, high contrast for readability
- **Imagery**: Illustrated figures, Nigerian landscapes, conflict symbols

### Slide Layout
- **Headline**: Large, bold, top of slide
- **Body**: 3-5 bullet points max
- **Visual**: Right side or bottom, not overwhelming
- **Footer**: Consistent with slide number

### Branding
- **Logo Placement**: Top-right or bottom-center
- **Tagline**: Include on most slides
- **Color Consistency**: Use brand colors throughout

### Technical Tips
- **Aspect Ratio**: 16:9 for presentations
- **File Format**: PDF for sharing
- **Animation**: Minimal, professional transitions
- **Font Size**: Headline 44pt+, Body 28pt+, Bullet 24pt+
